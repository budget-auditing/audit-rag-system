# Audit-OCIQA Demo (synthetic)

A small, **fully synthetic** dataset that mirrors the schema of the
Audit-OCIQA benchmark used in the TRACE paper. It exists only so that the
retrieval → evidence-chain → generation → evaluation pipeline can be run
end to end without access to the original data.

> **The Audit-OCIQA benchmark itself is not publicly released.** Every
> department, amount, and narrative in this folder was generated by
> [`tools/make_demo_dataset.py`](../../tools/make_demo_dataset.py) from a
> fixed random seed. None of it corresponds to any real organisation or
> budget, and metrics computed on it are **not** comparable to the
> numbers reported in the paper.

## Contents

| File | Rows | Purpose |
|---|---|---|
| `corpus.paragraphs.jsonl` | 96 | Evidence pool: 6 fictional departments × 2 fiscal years × 8 paragraphs |
| `gold.qrels.jsonl` | 31 | Queries with gold evidence ids |
| `qa.gold.jsonl` | 31 | Queries with gold OCI (Observation / Cause / Impact) claims and citations |
| `splits/test.jsonl` | 31 | Query list consumed by the pipeline (`--splits-dir`) |

Each fictional budget document contains a cover page, a revenue/expenditure
summary, a fiscal-appropriation summary, a general-public-budget expenditure
table, a basic-expenditure table, a project-expenditure table, a
government-fund table, and an explanatory note. Tables reconcile with each
other except where a risk is injected on purpose:

| Query template (`qid`) | Count | What it tests |
|---|---|---|
| `Q-demo-basic` | 12 | Basic-expenditure reconciliation across two tables (no risk) |
| `Q-demo-carry` | 10 | Reliance on prior-year carryover funds (cause not disclosed) |
| `Q-demo-special-gap` | 3 | Special-account funds only partly listed in the project table |
| `Q-demo-growth` | 6 | Year-over-year change stated in the note vs. computed from tables (2 mismatches injected) |

## Schema

Field names and formats follow the original benchmark:

```jsonc
// corpus.paragraphs.jsonl
{"evidence_id": "A2024-890c36fba0-0002", "doc_id": "890c36fba0", "pid": 2, "year": 2024,
 "budget_caliber": "unknown", "budget_level": "provincial", "section": "正文",
 "text": "## 一、收支预算总表\n...", "source_path": "corpus/dept-D05_2024.md"}

// gold.qrels.jsonl
{"row_id": "R000001-...", "qid": "Q-demo-basic", "split": "test", "query": "...",
 "gold_evidence_ids": ["A2023-...-0004", "A2023-...-0005"]}

// qa.gold.jsonl (adds year, doc_id, gold_oci)
{"gold_oci": {"Observation": [{"claim": "...", "cites": ["..."]}],
              "Cause": [...], "Impact": [...]}}
```

All amounts are in ten-thousand RMB (万元).

## Regenerating

```bash
python -m tools.make_demo_dataset            # writes datasets-public/audit-ociqa-demo/
python -m tools.make_demo_dataset --seed 7   # different synthetic sample
```
